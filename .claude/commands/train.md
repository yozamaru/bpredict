---
description: モデルを再学習して評価する
---

モデルを再学習し、採用可否を判断してください。

```bash
pytest batch/tests/test_leakage.py -v    # 先に通すこと
python -m batch.jobs.train
```

必ず報告する項目:

0. **評価サンプル数 n**（500未満なら以降の比較を行わず、現行モデル継続を報告する）
1. **同一の評価ウィンドウ**（直近2シーズン）で再評価した Brier と、現行モデルとの差の信頼区間**および点推定**
2. ベースライン3段との比較 — ホーム必勝 / **Elo単体ロジスティック回帰** / 全特徴ロジスティック回帰
3. ECE（等頻度10ビン）と、**そのモデルの予測分布から推定したノイズフロア95%点**
3b. **勝率の導出経路 A / B の Brier と ECE**（採用経路の判定）
3c. **`artifact_text` のバイト数**（1.5MB 上限に対する比率）
4. 特徴量の寄与度上位10件、寄与ゼロの特徴量、**各特徴量の欠損率**
5. `feature_list` の新旧差分
6. ゴールデンテスト（代表100試合）で予測が大きく変わった件数

採用基準（すべて満たす場合のみ有効化）:

- **n ≥ 500**（満たさなければ比較自体を行わない）
- Brier が現行より良く、差が**有意 かつ 実質的**（CIが0を跨がない **かつ** 点推定の差が0.003以上）
- Brier が Elo単体ロジスティック回帰を下回る
- **ECE < ノイズフロア95%点 × 1.5**（固定値0.05を使わない）
- 欠損率30%超の特徴量が存在しない
- **`artifact_text` が 1.5MB 以下**

**Accuracy は採用ゲートに使わない。表示専用。**（ホーム勝率60%の下ではベースラインと並ぶため、良いモデルを誤って棄却する。理想モデルとベースラインの差の SD は n=200 で 0.041 あり、`+0.03` はノイズと区別できない）

**検出力が足りないという理由で基準を緩めない。** 真の差0.03の検出確率は n=1,200 でも54.8%だが、これは「見逃す」方向の失敗であり、緩めれば「ノイズで誤って差し替える」方向の失敗に変わる。

基準未達なら有効化せず、理由を報告する。的中率が 75% を超えていたらリークを疑い `/check-leakage` を実行する。

学習の入力は `batch/snapshot/*.parquet` のみ。**D1 を読んでいないこと**（`test_training_reads_no_d1`）と `MANIFEST.json` の照合が通っていることを確認する。
