## 品質ゲート

以下をすべて満たす場合のみリリース可と判定する。

1. **A-01〜A-18 がすべて「満たしている」。「検証不能」が1件でもあればリリースしない**
2. CI がグリーン
3. `pytest batch/tests/test_leakage.py` が全件パス

未決事項 U-05（個人スタッツの表示人数）と U-06（エントリー情報の確定タイミング）が未確定の場合、A-01 と A-02 は判定できない。これらを先に確定させること。

**Phase 0 の実機検証（P0-11〜P0-16）が未完了の場合もリリースしない。** 設計は最も厳しい前提で書いてあり、実測で前提が覆る可能性がある項目（artifact サイズ、`batch()` のクエリ計上、ビルドファイル数、Zod のコスト、ECE ノイズフロア、勝率の導出経路）が残っている状態は「検証不能」に該当する。
