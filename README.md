# B.PREDICT（仮称）

B.LEAGUE PREMIER の試合について、勝敗確率・予想スコア・個人スタッツを統計モデルで予測し、**判断根拠と自身の的中率とともに**公開する非公式ツールです。

> **開発状況: 設計フェーズ。**
> 現在このリポジトリに含まれるのは設計文書のみで、アプリケーションは動作しません。
> 公開サイトはまだありません。

---

## 非公式であることについて

本プロジェクトは個人が制作する**非公式**のツールです。B.LEAGUE、所属クラブ、その他いかなる団体とも関係がなく、公式の情報や見解を代表するものではありません。

B.LEAGUE をはじめとする名称・商標は、それぞれの権利者に帰属します。

**プロダクト名「B.PREDICT」は仮称です。** 商標調査を経て正式名称を決定します。

## このツールがすること

- 試合ごとの**勝敗確率**（両チーム分）
- **予想スコア**（得点差と合計得点から導出）
- **個人スタッツ予測**（出場時間・得点・リバウンド・アシストから、フルボックススコアまで段階的に開示）
- **なぜその予測になったか**の提示（要因グループ別）
- **自身の的中率**（モデルバージョン別の推移と較正）

外れた試合を隠しません。結果画面で実績と対比し、「その確率帯の通算的中率」を併記します。予測の確からしさを利用者から隠さないことを、このツールの中心に置いています。

## このツールがしないこと

- **賭けに関する機能を持ちません。** 金銭やポイントを賭ける機能、ブックメーカーのオッズ参照、賭博サイトへの外部リンクは実装しません
- **記事本文・画像・ロゴを転載しません。** 扱うのは試合日程・スコア等の事実データのみです
- 取得したデータを一括配信・公開APIとして提供しません
- 選手個人の能力や資質を評価する表現を用いません（用いるのは「出場時間の減少」のような、公式記録から機械的に導ける事実の記述に限ります）

## 免責

- 予測は統計モデルによる推定であり、**外れます。**
- 設計時点の見積もりでは、的中率は64〜68%程度です。「ホームチームが必ず勝つ」と予想した場合が約60%であることを踏まえると、**改善幅は決して大きくありません。**
- 本ツールの予測は統計的推定であり、その正確性・完全性・有用性を保証するものではありません。本ツールの利用により利用者に生じた損害について、制作者は責任を負いません。**ただし、制作者の故意または重大な過失による場合は、この限りではありません。**
- **賭博その他の用途に使用しないでください。**

## データについて

公式サイトから、試合日程・スコア等の事実データを取得します。取得にあたっては次を守ります。

- `robots.txt` と利用規約をハッシュ照合し、変更を検知したら取得を停止する
- リクエスト間隔は最低3秒、並列取得なし、日次上限3,000リクエスト
- 429 / 503 を受けたら即座に中止する
- **取得した生HTMLは保存もコミットもしない**

出典表記は公開サイト上に明示します。

選手名など、公表されている個人に関する情報を扱います。取扱いの詳細は、公開時にプライバシーポリシーとして掲示します。
