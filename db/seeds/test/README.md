# テスト用シード

架空8クラブ × 2シーズンの**決定論的**なデータを生成する（基本設計 8.1 / 詳細設計 6.8）。

- **実在の選手名・クラブ名を使わない。** 個人情報を持たないため本番コピーも匿名化も不要
- 乱数は固定シードで、同じ入力から常に同じ結果を返す
- スキーマは `db/migrations/*.sql` をそのまま適用する（二重管理しない）

`generate.py` は SQL を書き出さずに、開いた SQLite 接続へ直接投入する。
約300試合ぶんの INSERT を SQL ファイルとしてコミットすると、生成物を手で直す誘惑が生まれ、
スキーマ変更のたびに巨大な差分が出る。生成元だけを持つ。

```python
from db.seeds.test.generate import seed_test_database
seed_test_database(connection)          # conftest の db フィクスチャが呼ぶ
```

## データの形

| 項目 | 内容 |
|---|---|
| クラブ | 8件（`t01`〜`t08`）。`club_seasons` は両シーズン分 |
| シーズン | `2024-25-B1` / `2025-26-B1` |
| 日程 | 1週末に4試合 × 土日の**2連戦**を14週。1シーズン112試合、合計224試合 |
| 会場 | 8件（各クラブのメイン会場）。`venue_revisions` に収容人数あり |
| 選手 | 1クラブ10名、計80名。`player_seasons` は両シーズン分 |
| スタッツ | チーム・選手の両方。恒等式（`pts = 2fgm×2 + 3fgm×3 + ftm` ほか）を満たす |
| Elo | `team_ratings` に試合日ごとのスナップショット |

**土日2連戦にしているのは、`series_game_no` と `rest_days_diff` を実際に動かすため**である
（B.LEAGUE の基本編成でもある。要件 6.2 の #10 #12）。
