## backfill は AI が実行する（2026-09-25 から）

運営者の指示により、`gh workflow run` で AI が起動する。**守ること。**

- **1日1シーズンを超えない**（D1 書き込み枠で1シーズンが66%を使う）
- **実行前に宣言し、枠と本日の実行履歴を確認する**
- **規約 / robots が変わったら絶対に承認せず、止めて報告する。** 承認は運営者のみ
- ログは `gh run view <id> --log` で AI が読む（スクリーンショットは不要）

`gh` は `yozamaru` として認証済み（スコープ `repo`）。Variables の読み書きもできる。
**Secrets は読めない**（設計どおり）。

## 気をつけること（実データで踏んだもの）

`verification/RESULTS.md` に詳細がある。**同じ罠を二度踏まないために、ここには見出しだけ置く。**

- 内部APIへのリクエストは **User-Agent を送る**（urllib の既定は Cloudflare が 403 で弾く）
- **1シーズンの D1 書き込みは約65,800行**（設計の見積り26,500行は外れていた）。1日1シーズンが上限
- 公式サイトから 429/503 を受けたら、クライアントがそのUTC日の取得を自動停止する。**朝（09:00 JST）まで待つ**
- D1 は `PRAGMA foreign_keys=OFF` を無視する。**データが入ったままでは参照されているテーブルを作り直せない**
- **日程の行は全部が `<a>` ではない。** 中止・延期の行はリンクを持たず、状態欄が
  `<script>` だけの行もある（2018-19 の CS）。1件で**シーズン全体が落ちた**。詳細設計 4.4
- 公式サイトは**たまに未対応のHTTPステータスを返す**（`ResponseError`）。再実行で通る
