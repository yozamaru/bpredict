# このサイトについて

B.PREDICT は、B.LEAGUE PREMIER の試合について **勝敗確率・予想スコア・個人スタッツ**
を統計モデルで予測し、その根拠と **自分の的中率** を併せて公開するツールです。

**公益社団法人ジャパン・プロフェッショナル・バスケットボールリーグ（B.LEAGUE）
および各クラブとは一切関係のない、個人が運営する非公式サービスです。**

## 大切にしていること

このサイトの価値は、予測がよく当たることそのものではありません。

1. **確率の目盛りが正しいこと** — 「70%」と出した試合が、実際におよそ 70% 勝つこと
2. **なぜその予測なのかが分かること**
3. **外した試合を隠さないこと** — 的中率は良いときも悪いときも同じ場所に出します

# 画面の見方

| 画面 | 何が見られるか |
|---|---|
| 今日の予測 | 当日の試合と勝率の一覧 |
| 日付別 | 日付を指定した試合一覧 |
| 試合詳細 | 試合前は勝率・予想スコア・根拠・個人スタッツ。試合後は実際の記録との対比 |
| 結果 | 終了した試合の、予測と実際の対比 |
| チーム | クラブの一覧。そこから各クラブのページへ |
| クラブ別 | 予測履歴、シーズン別・通算の戦績、当季の選手一覧 |
| 選手別 | 選手のシーズン別・通算のスタッツ（集計値のみ） |
| 的中率 | これまでどれだけ当たったか、確率の目盛りが合っているか |
| このサイトについて | 免責、データの出典、予測の仕組み、個人情報の取扱い、連絡先 |

## 勝率の読み方

**両チームの勝率を必ず並べて出します。** 片方だけでは誰の 68% なのか分からないためです。

- バーは **50% を軸** にして、優勢な側へ伸びます
- **45〜55% は「ほぼ互角」** と表示し、一方的な試合と見た目で区別します
- 色だけに頼らず、**位置（ホームが上）・数値・文字**でも優劣を示します

## 予想スコアの読み方

**整数で出します。** 予想スコアの誤差は 1 チームあたり平均 10 点前後あり、
小数第 1 位まで出すと、ない精度があるように見えてしまうためです。

勝率と予想スコアは **同じ値から導いています**。したがって
「ホーム 68% なのにスコアはアウェイ勝ち」という食い違いは起こりません。

## 個人スタッツの読み方

出場する確率が **50% 以上**と見積もった選手だけを出します。

- 初期表示は **出場時間・得点・リバウンド・アシスト**の 4 項目です
- 行を開くと全項目（フルボックススコア）が出ます
- **率は必ず分数と並べて出します**（`6.4 / 13.1 (48.9%)`）。
  1 試合のシュートは 6 本程度で、率だけを出すと、ない精度を主張することになります
- 試投数の予測が少ない選手には **率を出さず分数だけ**を出します
- **誤差の目安（±）は主要 4 項目にだけ**添えます。全項目に出すと画面が埋まるためです

### 注意して読んでいただきたい項目

- **スティール・ブロック**は 1 試合あたり平均 0.7 回程度で、誤差が平均値と同じ水準です。
  実質「その選手のふだんの値」を出しているだけに近く、付加価値はほとんどありません
- **シュート成功率**も 1 試合では試投数が少なく、誤差が大きい項目です
- **± (プラスマイナス) は予測しません。** チームの結果を個人に割り当てた指標で、
  1 試合での振れ幅が大きすぎるためです。**試合後の実際の記録としてのみ**出します

## 「この予測に使った項目」と「なぜこの予測になったか」

2 つは別のものです。

| | なぜこの予測になったか | この予測に使った項目 |
|---|---|---|
| 答えていること | **なぜそうなったか** | **何を見たか** |
| 単位 | 要因のグループ | 項目そのもの |
| 書き方 | 「ホーム有利」 | 「ホームが大きい」 |

**「使った項目」は有利・不利を主張しません。** 値の大小を並べているだけです。
どの項目がどれだけ効いたかは「なぜこの予測になったか」の側が示します。

# 4 つの状態表示

予測がどれくらい確かな状態で出ているかを隠さずに出します。

| 表示 | 意味 |
|---|---|
| **暫定** | 出場選手がまだ発表されていない段階の予測です。直近の出場傾向から推定しています |
| **確定** | 試合開始をもって凍結された予測です。**以後、一切変更しません** |
| **序盤** | 両チームとも今季の消化試合が少なく、予測がまだ安定しません |
| **更新遅延** | データの更新が 24 時間以上止まっています。表示は前回のままです |

## 「確定」は本当に変わりません

試合開始時刻を過ぎた予測は、**勝率も、予想スコアも、根拠も、個人スタッツも**
変更・削除できないようにしてあります（データベース側で禁止しています）。

**表示上の誤り（ラベルの誤字など）が見つかっても、過去の予測は直しません。**
後から直せるのであれば「予測を後から書き換えていない」という主張が成り立たなくなるためです。
直すのは以後の生成だけです。

# 的中率ページの読み方

上から順に、一般的な見方から専門的な見方へ並べています。

1. **ベースラインとの比較** — 「ホームが必ず勝つ」と予想した場合と比べてどうか
2. **予想スコアの誤差** — 1 チームあたり平均で何点ずれているか
3. **シーズン別の推移**
4. **モデルの版ごとの比較**
5. **確率の目盛りの合い方** — 「70% くらいと予想した試合が、実際には何 % 勝ったか」
6. **暫定・確定の内訳** — 出場選手の発表前と後で、当たり方がどう違うか
7. **詳しい指標**（折りたたみ）

**的中率には必ず母数（試合数）を併記します。** 「71%」だけでは、
7 試合中 5 試合なのか 312 試合中 223 試合なのかが分かりません。

## 外した試合について

試合詳細では、外した試合でも同じ形で結果を出します。そのうえで
**「68% と予想した試合は、これまで 42 試合中 29 試合（69.0%）が的中しています」**
のように、その確率帯の通算成績を併せて出します。

1 試合を外したことと、確率の目盛りが狂っていることは別のことだからです。

# データが出ないとき

| 表示 | 意味 |
|---|---|
| 「読み込んでいます。」 | 取得中です。待てば変わります |
| 「読み込めませんでした。」 | 取得に失敗しました。時間をおいてお試しください |
| 「〜に予定されている試合はありません。」 | その日に試合がありません |
| 「今シーズンの全日程が終了しました。」 | オフシーズンです |
| 「この試合の予測はまだありません。」 | 試合前日の朝に公開されます |
| 「的中率の記録はまだありません。」 | まだ 1 試合も照合していません |
| 「成績の記録はまだありません。」 | 集計がまだ走っていません |
| 「お探しのページはありません。」 | その URL のページはありません |

**3 つを同じ文言にしていません。** 取得中・失敗・データなしは別の状態です。

# 表示の設定

- **テーマ**（ライト / ダーク）はヘッダーのボタンで切り替えられます。
  アイコンは **押すと切り替わる先**を表します（ライトのときは月、ダークのときは太陽）
- 選択はお使いの端末に保存され、次回も保たれます

# 知っておいていただきたいこと

## 集計の範囲

戦績・スタッツの「通算」は、本サイトが取り込んだ **2016-17 シーズン以降**
（前身の B1 を含む）の記録です。リーグの歴史全体ではありません。

**不戦敗として処理された試合は含みません。** 実際にプレーしていない試合を
学習データに入れるとレーティングが歪むため、取り込んでいません。
そのため **公式の順位表と勝敗数が食い違う場合があります。**

## 出さないもの

- **ランキング**（得点王など）は出しません。選手同士の序列は示しません
- **選手個人の能力・資質への評価**を表す言葉は使いません。
  使うのは公式記録から機械的に導かれる事実の記述だけです
- **賭け事に関する機能・外部リンク・オッズ**は一切ありません

## 免責

本サイトの予測は統計的な推定であり、その正確性・完全性・有用性を保証するものでは
ありません。本サイトの利用により生じた損害について、当方は責任を負いません。
**ただし、当方の故意または重大な過失による場合は、この限りではありません。**

個人スタッツの予測は、選手個人の能力や将来の評価を示すものではなく、
過去の統計から算出された機械的な推定値です。

データは公式サイトから自動で取得しており、取得・変換の過程で誤り・欠落・遅延が
生じることがあります。**正確な情報は公式発表をご参照ください。**
